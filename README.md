# Advanced Excel Project – Biscuits Sales Analysis

## Project Overview
This project analyzes biscuit sales data to identify revenue trends, product profitability, customer purchasing patterns, payment preferences, and sales performance.

## Tools Used
- Microsoft Excel
- PivotTables and data analysis
- PowerPoint for presenting business insights

## Key Analysis
- Product-wise revenue, profit, and profit margin
- Revenue by gender and age group
- Top sales representatives
- Revenue by location
- Payment method analysis
- Key performance indicators (KPIs)

## Deliverable
Biscuits Sales Analysis PowerPoint presentation and Excel dataset.

## Objective
To convert sales data into meaningful insights that support business reporting and leadership decision-making.
